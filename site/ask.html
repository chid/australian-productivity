2. Ask in plain English

Claude reads the table descriptions, writes and runs SQL against the data in your browser, and explains the result. You need your own Anthropic API key, which is billed to your account.

Set your API key

The key is sent only to api.anthropic.com, straight from your browser. By default it is kept for this tab only; tick the box to remember it on this device. Don't use a key you share with others on a public computer.

Caveats

  • Never compare OECD and ILO levels directly: they use different price bases (2020 versus 2021 PPPs) and methods. Compare within one source.
  • ILO rows with status = 'projection' are modelled forecasts. Leave them out of any calculation.
  • Canada's 2020–24 growth-accounting averages are distorted by a 2021 outlier in the OECD file (MFP −13.0 points, capital deepening +8.9). Treat mfp_contrib_2020_2024 and capdeep_contrib_2020_2024 for Canada with caution.
  • AI answers can be wrong. Each answer shows the SQL it ran, so check it.
